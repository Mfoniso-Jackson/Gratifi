# Pilot Metrics Guide

The pilot dashboard focuses on proof that venues can deploy GratiFi and customers will use it.

## Primary Metrics

- Active pilot venues.
- Workers onboarded.
- QR codes generated.
- Recognition events per venue.
- Total tip volume.
- Stripe success rate.
- Moonbeam confirmation rate.

## Pilot Targets

- 5 independent venues.
- 100+ recognition events.
- 500+ QR scans.
- Strong qualitative feedback from owners and staff.

## Exporting

- Use `/admin/pilot` to export pilot CSV.
- Use each venue profile to export venue summary JSON.
- Use each case-study page to export markdown.
